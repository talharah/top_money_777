# Django Earning Platform

A full-stack earnings and task management platform built with Django and styled with a modern, responsive dark-themed Tailwind CSS interface.

## 🚀 Features

- **User Authentication:** Secure Login, Register, Logout, and Password Change functionality using Django's built-in auth system.
- **Responsive Dashboard:** Modern dark-themed UI built using Tailwind CSS and FontAwesome icons, complete with bottom navigation and back buttons.
- **User Profile & Settings:** Manage personal information, change passwords securely, and track account details.
- **Referral System:** Dynamic referral link generation (`/register/?ref=username`) to invite friends and track commissions.
- **Customer Support:** Integrated support ticket submission form, direct contact channels (Telegram/WhatsApp), and interactive FAQ accordion.
- **Admin Control:** Full management of users, tasks, deposits, and withdrawals via the Django Admin Panel.
